\paragraph{Design and analysis}
The additional batch was specified after the original results were known and frozen locally before its first completed task response. It reused all 24 public-table tasks and unchanged references under clean and correction annotations. Four policies crossed the boundary policy, binding A, the recorded truncated neutral extension and a completed neutral extension. The completed extension replaced only its last word, \texttt{subsequent}, with \texttt{review.}, giving the complete sentence ending ``for review.'' All three extensions contained 43 whitespace-separated words; tokenizer lengths were not assumed equal.

We accessed \texttt{deepseek-v4-flash} through \nolinkurl{https://amr-link.open-design.ai/v1}. This was a new model and service channel, rather than a repeat of the original Bailian DeepSeek-V3 endpoint. The provider-reported model identifier was recorded, but the underlying weights and routing were not independently verified. Each task-condition-policy cell received three fresh generations at temperature 0.2, with a 1,024-token cap, for 576 responses. No sampling seed or verified thinking-disable mode was requested. Usage records included reported reasoning tokens; their counts do not establish reasoning content or depth.

An interface amendment preceded the first completed task response. The third-party API rejected the original historical-tool message format without an explicit tool declaration. A synthetic-table probe then succeeded after declaring \texttt{fetch\_table} and setting \texttt{tool\_choice=none}. The same settings were frozen for every task request. No tool action was executed. The rejected requests and prior freeze are retained. This interface change, the token budget, model and service differences preclude attributing between-batch changes to the repaired prompt alone.

Within the new batch, binding A versus the complete control and complete versus truncated control used the same tasks, service and collection period. The original scoring functions were reused unchanged. The correction-condition parser interaction compared binding A with boundary. We averaged the three binary outcomes within each task before taking 10,000 paired-task bootstrap resamples, with NumPy seed 112323. Descriptive 95\% percentile intervals retain the task as the resampling unit. Repetition-specific contrasts and correct-out-of-three task counts describe generation variation; repetition indices do not imply common random seeds across policies. Full-24 results are primary for this batch, with the prior 21- and 15-task subsets retained as planned addendum sensitivities. The original and additional batches are reported separately.
